Upload curves in one of four CSV formats:

  1. INDEX_NAME,FREQUENCY_CODE,CURVE_DATE,HOUR_ENDING,OBSERVED_DATE_TIME,CURVE_VALUE
  2. INDEX_NAME,FREQUENCY_CODE,CURVE_DATE,HOUR_ENDING,CURVE_VALUE
  3. INDEX_NAME,FREQUENCY_CODE,CURVE_DATE,OBSERVED_DATE_TIME,CURVE_VALUE
  4. INDEX_NAME,FREQUENCY_CODE,CURVE_DATE,CURVE_VALUE
  1. The first version is the full version. Set hourEnding to zero for frequencies D and M, Observed date/time is supplied.
  2. The second version sets hour ending but defaults observed date/time to now.
  3. the third version skips hour ending but supplies observed date/time.
  4. The final version is the short version - no hour ending and defaults observed date/time.
